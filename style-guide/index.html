Kihon

Welcome to Kihon

Kihon (基本 — fundamentals) is the UI foundation for CyanAutomation. A lightweight, framework-free design system that brings consistency to web interfaces while preserving application independence.

This page demonstrates the design tokens, typography, colours, spacing, and foundational elements that make up Kihon v1.0.

      Accessibility Features

      Reduced motion

      If you have "Reduce motion" enabled in your system settings, animations and transitions on this page will be minimized. Try enabling it to see the difference.

      Forced colours mode

      If you use high-contrast or forced-colours mode, elements on this page should remain clearly visible and usable.

      Zoom and text resize

      Try zooming in (Ctrl/Cmd + Plus) or increasing text size in your browser settings. All content should remain readable and nothing should be clipped or hidden.

      Keyboard navigation

      Press Tab to navigate through all interactive elements. Press Shift+Tab to go backwards. Press Enter to activate buttons and links. Press Space to toggle checkboxes and radio buttons. Press Escape to close a dismissible modal dialog.
