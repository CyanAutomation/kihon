Phase 5A · Experimental reference patterns

One product, three ways to work

These framework-free examples explore how a training log can adapt its navigation, content density, and controls to the space and input in front of it. They use Kihon foundations and original CSS; they are not public components or Apple interface replicas.

Selected mode: dark.

Compact touch · iPhone

Capture a session

One clear task, grouped training details, comfortable touch controls, a persistent set of peer destinations, and safe-area-aware edges.

Open session capture

Try the form at a narrow viewport, then switch between light and dark.

Adaptive touch · iPad

Browse and inspect

A session list and selected detail share space when there is room. At a compact width the same selection becomes a clear single-column return path.

Open adaptive library

Search the list, choose a session, and resize to see the layout adapt.

Desktop · macOS

Review training history

A restrained sidebar, contextual report controls, accessible metrics, and an information-dense history view with keyboard-accessible actions.

Open analytics

Use Tab to move through the sidebar, filters, export action, and data.

How to use these references

The specification lives in docs/experience/. Each screen is built from semantic HTML, local CSS, and small demo-only JavaScript. The examples are excluded from the packaged consumer API.
